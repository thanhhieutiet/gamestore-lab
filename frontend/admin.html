Khu vực thử nghiệm Công cụ Lab

Thực hành mô phỏng các lỗ hổng bảo mật trực tiếp trên Server của Game Store.

Đọc File Hệ thống (Local File Inclusion)

Mô phỏng chức năng debug đọc tệp log của lập trình viên. Cho phép đọc bất kỳ tệp tin nào trên máy chủ thông qua đường dẫn tuyệt đối.


              

            


            
            

              

                
Xuất hóa đơn & Dispatch (OS Command Injection)

                
Chức năng kiểm toán dữ liệu đơn hàng bằng cách chạy command shell. Người dùng có thể nối chuỗi lệnh hệ thống vào tham số order_id.

              

              

                

                  
                  
                

                
              


              
              

                
                

              

            


            
            

              

                
Nhập dữ liệu Game qua XML (XML External Entity)

                
Mô phỏng tải danh sách game lên qua cấu trúc XML. Trình phân tích cú pháp của Server bật chức năng giải quyết thực thể ngoài (External Entities).

Cho phép biên dịch trực tiếp biểu thức logic dạng <%= express %>.
